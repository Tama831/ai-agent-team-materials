# Part 1: チートシート（印刷して手元に持つ用）

## 必要物品と使い方

## 研修医向け（30分版）タイムライン

| 時間 | 内容 | ファシリテーターの動き・声かけ |
|------|------|------------------------------|
| 0-3分 | 導入の問い + 学習目標 | 「優秀な医師1人 vs 専門チーム5人。どちらに任せたい？」→ 2-3人に聞く → 「AIでも同じ問いが立つんです」→ 目標読み上げ |
| 3-8分 | AIの3世代 + エージェント概念 | 3世代の表を順に説明。マルチエージェントの図は「チーム医療と同じ構造」を強調。「これ、みなさんが毎日やってることのAI版です」 |
| 8-14分 | Mount Sinai研究の詳細 | 研究概要表→結果3つを順に。「65分の1」は「月給の65分の1で同じ仕事ができたら？」と例える。救急外来の例で直感的理解 |
| 14-19分 | 批判的吟味 | 表を見せながら「この研究のここ、どう思います？」と対話的に。5つの問いを1つずつ投げる。正解はない |
| 19-23分 | ペアワーク | 「2人1組で。自分の現場でマルチエージェントAIが活躍する場面は？4分でどうぞ」 |
| 23-25分 | 全体共有 | 2-3ペアに発表。実現可能性と安全性の両面からコメント。「面白い！でも安全装置は？」 |
| 25-27分 | 業界トレンド | Gartnerの1,445%を紹介。human-on-the-loopの概念。「医療でどこまで許されるか？」 |
| 27-30分 | 持ち帰りの問い | アクションリストを見せて1つ選択。責任の問いを読み上げて終了 |

## 全スタッフ向け（15分版）タイムライン

| 時間 | 内容 | ファシリテーターの動き・声かけ |
|------|------|------------------------------|
| 0-2分 | 手挙げアンケート + 目標 | 「ChatGPTに質問したことある人？」→ 挙手 → 「仕事を任せたことは？」→ 少ない → 「ここが今日のテーマ！」 |
| 2-5分 | AIの進化（やさしく） | 「辞書 vs 新人スタッフ」の例えを使う。身近な例3つを順に。「こんなことができるようになりつつある」 |
| 5-8分 | Mount Sinai研究（要点だけ） | チーム医療との対比表が核心。「チーム医療の方が良いのは皆さんが一番知ってますよね。AIも同じでした」 |
| 8-11分 | グループワーク | 「3-4人で。AIに手伝ってほしい業務は？3分でどうぞ」→ 付箋を使うと盛り上がる |
| 11-12分 | 全体共有 | 各グループ1つ。「なるほど、それは近い将来実現しそうですね」と前向きに |
| 12-15分 | まとめ + 振り返り | 今後の予測表を見せる。最後のメッセージ「手を握れるのはあなただけ」を読む。参考文献配布 |

## 困ったときの対処法

| 状況 | 対処 |
|------|------|
| 「AIなんて信用できない」 | 「その懸念は正しいです。Mount Sinai研究でも安全性は今後の課題です。だからこそ医療者がAIを理解して、適切に監督する力が必要なんです」 |
| 「仕事を奪われるのでは？」 | 「これまでの技術革新（電子カルテ、自動分注器等）で人が不要になりましたか？むしろ人間にしかできない業務に集中できるようになった。AIも同じです」 |
| 技術的に深い質問が来た | 「素晴らしい質問です。参考文献の論文にその点が詳しく書かれています。後でURLをお渡ししますね」→ 深入りしない |
| 「うちの病院には関係ない」 | 「3年前、電子カルテが入る前も同じことを言われました。準備は早い方がいい。今日の勉強会がその第一歩です」 |
| 時間が押してきた | グループワークを1分短縮。最後のメッセージだけは必ず伝える |

## ブルームの分類法 — 対象者別学習目標

### 研修医・専攻医（30分）
| レベル | 到達目標 | 評価方法 |
|--------|---------|---------|
| 理解 | マルチエージェントAIの基本概念を**説明できる** | 3世代の違いを自分の言葉で言えるか |
| 分析 | Mount Sinai研究のStudy Designを**批判的に吟味できる** | 5つの問いに対して自分の見解を述べられるか |
| 創造 | 自分の臨床現場でのAI活用可能性を**1つ提案できる** | ペアワークで具体的な提案が出るか |

### 全スタッフ（15分）
| レベル | 到達目標 | 評価方法 |
|--------|---------|---------|
| 理解 | AIエージェントの基本的な仕組みを**理解する** | 「辞書と新人スタッフの違い」を説明できるか |
| 適用 | 医療AIが自分の業務にどう関わるか**イメージできる** | グループワークで具体例が出るか |
