## チートシート 4: 医療DX関連の変更まとめ

### 加算の再編

| 旧制度 | 新制度 |
|--------|--------|
| 医療DX推進体制整備加算 | **廃止** |
| 医療情報取得加算 | **廃止** |
| ↓ 統合 | |
| **電子的診療情報連携体制整備加算** | **新設** |

### 新加算の3区分

| 区分 | 初診点数 | 再診点数 | 主な要件 |
|------|---------|---------|---------|
| **区分1** | **15点** | 2点 | 電子処方箋発行**実績** + 電子カルテ情報共有サービス利用 + マイナ保険証利用率**30%以上** |
| **区分2** | **9点** | 2点 | 電子処方箋発行体制（実績or導入計画）+ DXシステム整備 |
| **区分3** | **4点** | 2点 | マイナ保険証利用体制（オンライン資格確認）+ 基本DXシステム |

### 評価軸の転換ポイント

> **「体制の整備」→「実績・アウトカム」へ**
> - 電子処方箋の「体制あり」ではなく「発行実績」が必要
> - マイナ保険証の「導入済み」ではなく「利用率30%以上」が条件
> - 「準備しました」から「使われています」への転換

### 診療録管理体制加算の再編
- サイバーセキュリティ対策が加算要件に追加
- 電子カルテ情報共有サービスへの参加も評価

## 困ったときの対処法

| 状況 | 対処 |
|------|------|
| **「結局、自分の給料はいくら上がるの？」** | 「病院全体の収入は確実に増えます。ベースアップ評価料の原資が全職員に使えるので、これから具体的な配分が決まります。管理部門の動きに注目してください」 |
| **「BCPなんて作っても意味がない」** | 「能登半島地震の経験が背景にあります。実際に被災した医療機関では、BCPがあったところとなかったところで対応に大きな差が出ました」 |
| **「マイナ保険証を嫌がる患者さんにどう対応？」** | 「強制ではありません。でも利用率が病院の収入に影響するので、メリットを伝えて自然に促す声かけが大切です」 |
| **「改定の内容が多すぎて覚えられない」** | 「全部覚える必要はありません。あなたの部署に関係する1-2項目だけ押さえてください。チートシートを配るので、いつでも確認できます」 |
| **「ディスカッションが盛り上がらない」** | 「では具体的に聞きます。マイナ保険証の利用、今の窓口でどうしていますか？」と実務に引き寄せる |
| **時間が余った** | 「もう1つ。BCP策定、あなたの部署で最初にやるべきことは何だと思いますか？」で追加ディスカッション |
| **時間が足りない** | Slide 5（部署別アクション）を「配布資料参照」に短縮。ディスカッションを1分に圧縮 |
