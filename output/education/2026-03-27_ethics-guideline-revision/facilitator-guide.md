## 困ったときの対処法

| 状況 | 対処 |
|------|------|
| **「改正はまだ確定してないのでは？」** | 「いまは確定しています。2026年8月27日に告示され、12月1日から適用です（実施中の研究には経過措置あり）。**施設の倫理審査委員会の運用も確認しておきましょう**」 |
| **「うちの施設ではどうなるのか」** | 「施設ごとの対応は倫理審査委員会の事務局に確認が必要です。今日の教材は**判断の枠組み**を持ち帰る場です」 |
| **ワークの時間が足りない** | シナリオを1つに絞る。「全員シナリオAでやりましょう」と指定すると時間短縮 |
| **ワークで「分からない」が多い** | Slide 12の同意の型の表を指さして「ここに当てはめてみてください」と誘導 |
| **指導医から詳細な法的質問** | 「素晴らしい質問です。改正の確定版テキストと合わせて、参考文献の合同会議資料に詳細があります」→ 深入りしない |
| **時間が3分余った** | 「では、自分が今関わっている研究で、改正の影響を受ける部分を1つ挙げてください」と追加ディスカッション |
| **時間が3分足りない** | 前提確認（スライドなし）を省略、フィードバック（スライドなし・配布物）を「答えは配布資料参照」に短縮 |

# Part 2: チートシート詳細資料

## A. 改正前後の変更点比較表

| 項目 | 改正前（現行指針） | 改正後（新指針） | 実務への影響 |
|------|-------------------|-----------------|-------------|
| **同意手続きの構造** | 複数の同意類型が場面ごとに分岐し複雑 | **ICとオプトアウトの二元化**で簡素化 | 研究計画書での同意手続き記載がシンプルに |
| **仮名加工情報の利用** | 指針上の規定あり | **個人情報保護法の規定に沿って取り扱う**（指針による上乗せ規制は解消） | 法の規定とあわせて確認する |
| **匿名加工情報の利用** | 「適切な同意を受けることが困難な場合」という要件 | 要件は整理され、**個人情報保護法の規定に沿って取り扱う** | 法の規定とあわせて確認する |
| **包括同意の扱い** | 包括同意のみでの研究利用の可否が不明確 | 包括同意の範囲内で研究内容を特定し、**オプトアウト手続き実施**で利用可 | バイオバンク研究の手続きが明確化 |
| **「適切な同意」** | 指針独自の用語 | 用語・規定を**削除**（「IC」と「オプトアウト」に整理） | 手続きの選択が分かりやすくなる |
| **個人関連情報** | 明確な規定なし | **個人情報保護法の規定に沿って取り扱う** | 法の規定とあわせて確認する |
| **指針の複雑さ** | 度重なる改正で複雑化、「研究停滞の一因」との指摘 | **簡潔化**を主眼に再構成 | 研究者の負担軽減、審査の効率化 |

## B. オプトアウト vs 包括同意 vs インフォームドコンセントの整理

### 定義と比較

| | インフォームドコンセント（IC） | オプトアウト | 包括同意（Broad Consent） |
|---|---|---|---|
| **定義** | 研究の目的・方法・リスク等を説明し、対象者の自由意思による書面同意を取得 | 研究に関する情報を公開し、対象者が拒否できる機会を保障 | 将来の不特定の研究利用を含む広範な同意を事前に取得 |
| **同意の時期** | 研究参加前 | 研究実施前（情報公開による） | 試料・情報の収集時 |
| **対象者の行動** | 積極的に「同意する」と意思表示 | 嫌なら「拒否する」と意思表示 | 将来の利用も含めて「同意する」と意思表示 |
| **法的根拠** | 個人情報保護法 + 倫理指針 | 倫理指針（個人情報保護法のオプトアウトとは別概念） | 倫理指針 |
| **適用場面（改正後）** | 侵襲を伴う研究、新規試料採取 | 既存試料・情報の利用 | バイオバンク等（ただし**単独では不十分**、オプトアウトとの併用が必要） |

### 注意点
- **倫理指針のオプトアウト** と **個人情報保護法のオプトアウト** は別概念
  - 倫理指針: 研究対象者への情報公開と拒否機会の保障
  - 個人情報保護法: 第三者提供における本人の事前拒否権（法27条2項。旧23条2項から条番号が移動）
- 包括同意は「万能の同意」ではない → 改正後は**オプトアウトとの組合せ**が明確に求められる

## C. 仮名加工情報 vs 匿名加工情報の違い

| | 仮名加工情報 | 匿名加工情報 |
|---|---|---|
| **定義** | 他の情報と照合しなければ特定の個人を識別できないように加工した個人情報 | 特定の個人を識別できないように加工し、かつ**復元できないように**した情報 |
| **個人の特定可能性** | 照合すれば特定可能（対応表が存在しうる） | 特定不可能（不可逆的に加工） |
| **加工の例** | 氏名→ID番号に置換、生年月日→年齢に変換（対応表を保持） | 氏名削除、年齢を10歳刻みに丸め、住所を都道府県のみに（対応表も破棄） |
| **第三者提供** | 原則禁止（法41条の規律） | 一定の条件下で可能（法43条の規律） |
| **研究利用（改正後）** | **個人情報保護法の規定に沿って取り扱う**（指針の上乗せ規制は解消） | **個人情報保護法の規定に沿って取り扱う**（指針の上乗せ規制は解消） |
| **倫理審査** | 必要 | 必要（ただし簡略化の余地あり） |
| **実務上の使い分け** | 同一施設内の研究で、後から元データに戻る可能性がある場合 | 多施設共同研究、データ共有、公開データセット |

### よくある間違い
- 「仮名加工したから匿名」→ **間違い**。仮名加工は対応表があれば個人に戻せる
- 「匿名加工したらもう個人情報ではない」→ **正しい**。ただし加工基準を満たす必要あり
- 「匿名加工は安全だからチェック不要」→ **間違い**。加工方法の妥当性は倫理審査で確認

## D. 研究計画書チェックリスト（新指針対応版）

### 基本事項
- [ ] 研究タイトル、研究責任者、実施機関を記載した
- [ ] 研究の目的と意義を明記した
- [ ] 研究デザイン（前向き/後ろ向き、介入/観察等）を記載した

### 対象者と試料・情報
- [ ] 対象者の選定基準・除外基準を明記した
- [ ] 使用する試料・情報の**種類を正確に分類**した
  - [ ] 個人情報 / 仮名加工情報 / 匿名加工情報 / 個人関連情報
- [ ] 試料・情報の**取得元**を明記した（自機関 / 他機関 / バイオバンク等）
- [ ] 新規取得か既存利用かを明記した

### 同意手続き（改正対応の核心部分）
- [ ] **同意の方法を正しく選択**した
  - [ ] 侵襲あり・新規試料採取 → インフォームドコンセント
  - [ ] 既存試料・情報の利用 → オプトアウト（改正後の基本）
  - [ ] 仮名加工情報・匿名加工情報 → 個人情報保護法の規定に沿って取扱う（指針の上乗せ規制は解消）
  - [ ] 包括同意取得済み → 範囲内特定 + オプトアウト手続き
- [ ] オプトアウトの場合、**情報公開の方法**を具体的に記載した
  - [ ] 掲示場所（院内掲示板、ウェブサイト等）
  - [ ] 公開期間
  - [ ] 拒否の連絡先・方法
- [ ] ICの場合、**説明文書と同意書**を作成した

### 個人情報の管理
- [ ] 仮名加工の具体的方法を記載した（該当する場合）
- [ ] 匿名加工の基準・方法を記載した（該当する場合）
- [ ] 対応表の管理方法を記載した（仮名加工の場合）
- [ ] データの保管場所・保管期間・廃棄方法を記載した
- [ ] **個人情報保護法との整合性**を確認した

### 倫理審査
- [ ] 倫理審査委員会への申請準備ができている
- [ ] 利益相反の開示を記載した
- [ ] 研究対象者への補償（該当する場合）を記載した

### 新指針固有の確認事項
- [ ] 改正後の指針に基づいて同意手続きを選択している（改正前のルールで書いていないか確認）
- [ ] 「適切な同意」の定義が個人情報保護法と整合しているか確認した
- [ ] 他機関への試料・情報提供がある場合、提供先のルールも確認した

## ブルームの分類法による学習目標

| **創造** | 新指針に準拠した研究計画書の骨子を作成できる | （スライドなし・配布物） | ワークシートの完成度、同意方法の正確性 |

## セッション設計の工夫

### 15分という制約への対応
- **情報量の厳選:** 改正内容は多岐にわたるが、「同意手続き」と「情報の分類」の2軸に絞った
- **チートシートへの委譲:** 詳細な比較表やチェックリストはファシリテーターガイドに収録し、セッション後の参照資料として配布
- **ハンズオンの時間確保:** 15分中4分（27%）をハンズオンに充当。短時間でも「やってみる」体験を優先

### 「ミニ研究計画書ワーク」の設計意図
- たまさんの「研究計画書を書くのも楽しそう」というコメントに対応
- 3シナリオ選択制: 参加者の研究経験・興味に合わせて自己決定できる
- **シナリオA**（カルテ研究）: 最も身近で初学者向け
- **シナリオB**（バイオバンク）: 包括同意の扱いを体験
- **シナリオC**（AI研究）: 匿名加工情報の扱い（個人情報保護法の規定に沿う）を体験
