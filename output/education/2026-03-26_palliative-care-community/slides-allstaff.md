# 地域で支える緩和ケア — 私たちにできること

**対象**: 全スタッフ（看護師・介護士・事務職員・リハビリ職等）
**所要時間**: 20分
**IDモデル**: ガニェの9教授事象
**作成日**: 2026-03-26

---

## スライド1: タイトル

### 地域で支える緩和ケア
### — 私たちにできること

```
所要時間: 20分
今日のルール: 正解を求めません。感じたことを大切にしてください。
```

## スライド2: 問いかけ（注意の喚起）

### あなたが関わっている利用者さんの中で...

> 「この方、最近つらそうだな」
> 「もう少し何かできることがあるんじゃないかな」

と感じたことはありませんか？

**→ その「気づき」こそが、緩和ケアの出発点です。**

🎯 *ガニェ第1事象: 学習者の注意を喚起する*

---

## スライド3: 今日のゴール（学習目標の提示）

### 今日、持って帰ってほしいこと

1. 緩和ケアは「終末期だけのもの」ではないとわかる
2. **あなたの職種**でできる緩和ケアが1つ見つかる
3. 困ったときに誰に相談すればいいかがわかる

```
「自分には関係ない」→「自分にもできることがある」
この変化が今日のゴールです。
```

🎯 *ガニェ第2事象: 学習目標を知らせる*

## スライド4: まず、誤解を解きましょう（前提条件の想起）

### 「緩和ケア」と聞いて、何を思い浮かべますか？

よくある誤解：

| 誤解 | 実際 |
|---|---|
| 終末期の人だけが受けるもの | 診断されたときから始められる |
| がんの人だけが対象 | 心不全、認知症、呼吸器疾患なども対象 |
| 特別な専門家だけがやること | **すべての職種が関われる** |
| 「もう何もできない」ということ | 「できることはまだたくさんある」ということ |

🎯 *ガニェ第3事象: 前提条件を思い出させる*

## スライド5: WHOの定義をやさしく

### 緩和ケアとは

> 重い病気に向き合う患者さんとご家族の
> **「つらさ」を和らげて**
> **その人らしい生活を支える**こと

「つらさ」には4つの種類があります：

```
┌──────────────────────────┐
│     体のつらさ            │  痛み、息苦しさ、だるさ
├──────────────────────────┤
│     心のつらさ            │  不安、悲しみ、怒り
├──────────────────────────┤
│  人とのつながりのつらさ    │  孤独、家族との関係
├──────────────────────────┤
│  生きる意味のつらさ        │  「何のために生きているのか」
└──────────────────────────┘
```

**体のつらさだけが緩和ケアではありません。**

🎯 *ガニェ第4事象: 新しい内容を提示する*

---

## スライド6: 地域包括ケアの中の緩和ケア

### 地域包括ケアシステムと緩和ケア

```
        ┌─ 医療（病院・診療所・訪問診療）
        │
地域包括 ─┼─ 介護（施設・在宅サービス）  ← ここにいるのが皆さん
ケア    │
        ├─ 予防（健康づくり）
        │
        └─ 生活支援（住まい・見守り）
```

**緩和ケアは、このすべてに横串を通すもの。**

利用者さんの「つらさ」は、医療の場だけでなく、介護の場、生活の場で日々感じられている。

## スライド7: 衝撃のデータ

### 知っていましたか？

日本緩和医療学会の全国調査（528施設）によると...

```
■■■■■■■■■■ 50%   医療従事者向けの緩和ケア教育を実施
■                10%   介護職向けの緩和ケア教育を実施
```

**介護職は、利用者さんと最も長い時間を過ごしているのに、
緩和ケアについて学ぶ機会が最も少ない。**

| 1日の接触時間（施設の場合） |
|---|
| 介護職: 8-16時間 |
| 看護師: 1-2時間 |
| 医師: 数分-数十分 |

→ **一番近くにいるあなたの「気づき」が、一番大切。**

🎯 *ガニェ第4事象: 新しい内容を提示する（データで実感を促す）*

## スライド8: あなたの職種でできること

### 緩和ケアは特別なことではありません

| 職種 | あなたにできる緩和ケア |
|---|---|
| **介護士** | 日常の変化に気づく。「いつもと違う」を伝える。声かけ、傾聴、安楽な姿勢の工夫 |
| **看護師** | 症状の評価、医師への報告、ケアプランへの反映、介護職の相談窓口 |
| **リハビリ職** | 「できること」を維持する支援、動作時の痛みの評価、リラクゼーション |
| **事務職員** | 家族への丁寧な対応、環境整備、情報連携のサポート |
| **栄養士** | 食べたいものを聞く、食べやすい形態の工夫、栄養より「楽しみ」 |
| **相談員** | 家族の不安への寄り添い、社会資源の紹介、意思決定の支援 |

**「自分の仕事の延長線上」に緩和ケアはあります。**

🎯 *ガニェ第5事象: 学習の指針を与える*

## スライド9: 具体的な場面で考えてみましょう

### 場面1: 朝の声かけ

いつもの「おはようございます、よく眠れましたか？」

これだけで立派な緩和ケアのアセスメントです。

**+ひと言の例**：
- 「体のどこか痛いところはありませんか？」
- 「何か気になっていることはありますか？」
- 「昨日のお薬は楽になりましたか？」

### 場面2: 食事の場面

食事量が減ってきた利用者さんに：
- ❌ 「ちゃんと食べないと元気になれませんよ」
- ✅ 「食べたいものはありますか？少しでも好きなものを」

### 場面3: 入浴の場面

入浴を嫌がるようになった利用者さん：
- 痛みで動くのがつらい？
- 裸になることへの抵抗？
- 体力が落ちて疲れる？
- → **「嫌がる」の背景を考えること = 緩和ケア的思考**

## スライド10: グループワーク（5分間）

### 3-4人グループで話してみましょう

> **「あなたが関わった利用者さん（患者さん）で、
> もっとこうできたらよかったな、と思ったことは？」**

ルール：
- 正解はありません
- 批判しない、聞くことに集中
- 「自分だったらどうする？」を考えてみる
- 個人情報に配慮（名前は出さない）

**1人1分ずつ話して、残り1分で「共通点」を見つけてください。**

🎯 *ガニェ第6事象: 練習の機会を与える*

---

## スライド11: グループワークの共有

### いくつかのグループに聞いてみましょう

```
ファシリテーターが2-3グループに発表を依頼

ポイント:
- 「気づいていた」のに「何もできなかった」経験が多い
- → それは「知識がなかった」のではなく「伝え方を知らなかった」だけ
- 今日からその「伝え方」を一つずつ学んでいきましょう
```

🎯 *ガニェ第7事象: フィードバックを与える*

## スライド12: 困ったときの相談先

### 一人で抱えないでください

```
あなたが「何かおかしい」と感じたら：

Step 1: まず看護師に伝える
        「〇〇さん、いつもと違って△△な様子です」

Step 2: 看護師が判断して医師に報告
        → 必要に応じて緩和ケアチームに相談

Step 3: カンファレンスで情報共有
        あなたの「気づき」がチーム全体のケアを変える
```

**大切なのは「正確な医学的判断」ではなく、
「いつもと違う」と感じたことを伝えること。**

| 連絡先 | 役割 |
|---|---|
| フロアの看護師 | 日常の気づきの第一報告先 |
| 施設看護師長 | 看護師不在時の相談先 |
| 施設医師 | 症状の評価と治療方針 |
| 地域の緩和ケアチーム | 専門的な相談（施設から依頼） |

※ 施設ごとの連絡先は別紙参照

## スライド13: 多職種で支えるということ

### 一人で抱えない。チームで支える。

```
利用者さん・ご家族
      ↑
  ┌───┼───┐
  │   │   │
介護  看護  医師
  │   │   │
  ├───┼───┤
  │   │   │
リハ  栄養  相談員
  │   │   │
  └───┼───┘
      │
  事務・その他

全員の「気づき」が集まって、
はじめて「その人らしいケア」が実現する
```

**介護職の「気づき」は、医師や看護師には見えないものを含んでいます。
あなたの目は、かけがえのないものです。**

## スライド14: まとめ

### 今日のまとめ — 3つだけ覚えてください

```
1. 緩和ケアは「終末期だけ」「がんだけ」のものではない
   → つらさを和らげること、すべてが緩和ケア

2. あなたの「いつもと違う」という気づきが出発点
   → 専門知識がなくても大丈夫。感じたことを伝えよう

3. 一人で抱えない。看護師に伝えることから始めよう
   → あなたの一言がチームのケアを変える
```

## スライド15: 小さな一歩から

### 明日からできる「たった一つのこと」

**今日のワーク:**

> 明日から、利用者さんに一つだけ
> いつもの声かけに**「＋ひと言」**を加えてみてください。
>
> 例: 「痛いところはありませんか？」
> 例: 「何か気になることはありますか？」
> 例: 「最近、眠れていますか？」

📝 **ワークシート（配布）に書いてください：**
- 「明日から試してみたい＋ひと言」を1つ
- 1週間後に「やってみてどうだったか」を共有する時間を設けます

🎯 *ガニェ第8・9事象: 学習の成果を評価する / 保持と転移を促進する*

## スライド16: おわりに

### 緩和ケアは、特別なことではありません。

> 目の前の人の「つらさ」に気づき、
> 寄り添い、伝える。
>
> それは、皆さんが毎日していることの延長線上にあります。
