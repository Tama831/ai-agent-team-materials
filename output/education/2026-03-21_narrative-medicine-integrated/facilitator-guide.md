# Part 1: チートシート（印刷して手元に持つ用）

## 必要物品と使い方

| 物品 | 用途 | 準備のコツ |
|------|------|-----------|
| タイマー | ペアワーク・グループワークの時間管理 | 参加者全員に見える位置に置く。討論時間は厳守（延長すると後が押す） |
| A4用紙 + ペン | グループワークのメモ用（全スタッフ版） | 各テーブルに2-3枚。書くことで思考が整理される |
| 参考文献プリント | 配布用（Part 3を印刷） | 最後に配布。先に配ると読み始めてしまう |
| ホワイトボード/模造紙 | 全体共有時の記録用（任意） | なくてもOK。口頭共有だけでも十分 |

## 研修医向け（30分版）タイムライン

| 時間 | 内容 | ファシリテーターの動き・声かけ |
|------|------|------------------------------|
| 0-3分 | 導入の問い + 学習目標 | 「最近診た患者さんの中で、病歴だけでは捉えきれなかった"何か"を感じた経験はありますか？」→ 2-3秒沈黙を作る → 目標を読み上げる |
| 3-7分 | ナラティブの理論 + 課題 | Rita Charonの3要素を簡潔に。Frontiers論文の課題4つは「実はこんな壁がある」と率直に伝える |
| 7-12分 | デジタル・ナラティブ | JMIRの3つの方向性を説明。「限界と批判的視点」も必ず触れる。「良いことばかりじゃない」が研修医にとって重要 |
| 12-17分 | ナラティブ×臨床思考 | BMC論文の結果を紹介。統合モデルの概念図を示す。批判的吟味のポイント4つを一緒に考える |
| 17-21分 | ペアワーク | 「2人1組で。あなたの臨床現場で統合を1つ実践するなら何ができるか？4分間でどうぞ」 |
| 21-23分 | 全体共有 | 「どんなアイデアが出ましたか？」→ 2-3ペアに聞く → 具体的なアクションレベルに落とすコメント |
| 23-27分 | 3論文の統合 | 表を見せて全体像を確認。「レバレッジポイントはどこ？」の問いを投げる |
| 27-30分 | 持ち帰りの問い | アクションリストを見せて1つ選んでもらう。最後の問いを読み上げて終了 |

## 全スタッフ向け（15分版）タイムライン

| 時間 | 内容 | ファシリテーターの動き・声かけ |
|------|------|------------------------------|
| 0-2分 | 物語の紹介 + 目標 | おばあちゃんのエピソードをゆっくり読む。「今日のゴールは2つだけ」と伝える |
| 2-5分 | ナラティブ・ケアとは | 表で「病歴 vs 物語」の違いを見せる。「どれかピンと来るもの、ありますか？」と軽く聞く |
| 5-8分 | デジタルの可能性 + 職種別 | 職種別の表を見せる。「あなたの職種だからこそ聴ける物語がある」を強調 |
| 8-11分 | グループワーク | 「3-4人で。最近聴いた心に残った一言は？3分でどうぞ」 |
| 11-13分 | 全体共有 | 各グループから1つずつ。「素敵ですね」「それ、チームで共有したら嬉しいですよね」と肯定 |
| 13-15分 | 1日1聴チャレンジ | 職種別アクション表を見せる。「どれか1つ、明日やってみてください」。参考文献配布 |

## 困ったときの対処法

| 状況 | 対処 |
|------|------|
| 誰も発言しない | 「じゃあ隣の人と30秒だけ話してみて」→ ペアで話すと発言しやすくなる |
| 1人が話しすぎる | 「ありがとうございます！他の方のお話も聞いてみたいです」→ 笑顔で切る |
| 「ナラティブなんて時間ない」と否定的意見 | 「おっしゃる通り、Frontiers論文でもそれが最大の課題として指摘されています。だからこそ"1日1聴"のような最小単位から始める意味があるんです」 |
| 涙ぐむ参加者がいる | 無理に止めない。「大切な思い出をありがとうございます」。全体が気まずくなったら「こうした感情が動くこと自体が、ナラティブの力なんです」 |
| 時間が押してきた | ペアワーク/グループワークを1分短縮。持ち帰りの問いだけは必ず伝える |

# Part 2: インストラクショナルデザイン

## ガニェの9教授事象マッピング

| # | 事象 | 研修医30分版 | 全スタッフ15分版 |
|---|------|-------------|----------------|
| 1 | 注意の喚起 | 「病歴では捉えきれない何か」の問い | おばあちゃんのエピソード |
| 2 | 学習目標 | 3つの到達目標（理解・分析・創造） | 2つの到達目標（理解・適用） |
| 3 | 前提条件の想起 | Rita Charonフレームワーク + 既知概念接続 | 「病歴 vs 物語」の日常的な対比 |
| 4 | 新しい内容の提示 | 3論文の知見 + 批判的視点 | ナラティブ・ケアの概念 + 具体例 |
| 5 | 学習の指針 | 統合モデル概念図 + 批判的吟味ポイント | 職種別「聴くチャンス」表 |
| 6 | 練習の機会 | ペアワーク: 統合実践のアイデア出し | グループワーク: 心に残った一言の共有 |
| 7 | フィードバック | ファシリからの具体化コメント + 全体共有 | 肯定的フィードバック + 全体共有 |
| 8 | 成果の評価 | 「レバレッジポイントはどこ？」 | 「1日1聴」のアクション選択 |
| 9 | 保持と転移 | 来週の1アクション + 持ち帰りの問い | 1日1聴チャレンジ + 参考文献配布 |

## ブルームの分類法 — 対象者別学習目標

### 研修医・専攻医（30分）
| レベル | 到達目標 | 評価方法 |
|--------|---------|---------|
| 理解 | ナラティブ・メディスンの理論的背景を**説明できる** | スライド2-3の内容を自分の言葉で言い換えられるか |
| 分析 | デジタル・ナラティブの可能性と限界を**論じられる** | 批判的吟味のポイントに沿って議論できるか |
| 創造 | 臨床思考との統合アプローチを**1つ導入する計画を立てられる** | ペアワークで具体的なアクションプランが出るか |

### 全スタッフ（15分）
| レベル | 到達目標 | 評価方法 |
|--------|---------|---------|
| 理解 | ナラティブ・ケアの基本概念を**理解する** | 「病歴と物語の違い」を自分の言葉で言えるか |
| 適用 | 自分の業務で患者の物語を活かす方法を**1つ挙げられる** | 「1日1聴」のアクションを選択できるか |
