- (任意)タイマー

### タイムライン

| 時間 | セクション | 声かけセリフ例 |
|---|---|---|
| 0:00-2:00 | 導入 + 持ち帰り3つの予告 | 「今日のゴールは、明日の外来で1問試せるようになることです。後半に進むにつれて視野が広がっていきますが、置いていきません」 |
| 2:00-6:00 | 症例 + 「次の一手は?」隣と30秒 | 「30秒、隣の人と相談してください。診断ではなく、自分なら次に何を聞くか/するか、で結構です」 |
| 6:00-9:00 | 「繋がりの見方」種明かし | 「カルテに書かれていない情報をスライドに出します。これがあったら、皆さんの一手は変わりましたか?」 |
| 9:00-13:00 | 3つのフレーム転換 + 表 | 「左が今までのやり方、右がWHOの提言です。左が悪いわけではありません。両方を持ち替えできるようになるのが目標です」 |
| 13:00-16:00 | 明日の1問 + ふりかえりの型 | 「明日の外来の1人目で1回だけ試してみてください。失敗してもOKです」 |
| 16:00-19:00 | 半径を広げる(チーム→外来導線→自院→世界) | 「ここからは、すぐにはできないけど "知っておくと外来の見え方が変わる" 話をします」 |
| 19:00-20:00 | まとめ + 任意の宿題 | 「次回、試してみた話を1人1分で共有します」 |

### 困ったときの対処法

- **症例ワークで誰も発言しない** → 「正解はないので、まず "何を聞きたいか" を1人1つだけでOKです」
- **「家庭医みたいなことは専門医にはできない」と言われたら** → 「全部やる必要はありません。3つのうち1つだけでも持ち替えられたら今日は十分です」
- **時間が押したら** → Part 4(チーム/外来導線)を5分短縮し、「視野を広げる延長線上の話」とだけ触れる
- **時間が余ったら** → ホワイトボードにその場の1症例を書き出してもらい、繋がりを一緒に探すワークに切り替える

## 2. インストラクショナルデザイン

### IDモデル: ガニェの9教授事象

| # | 教授事象 | 本教材での実装 |
|---|---|---|
| 1 | 注意の獲得 | 65歳男性糖尿病症例の「次の一手は?」問いかけ |
| 2 | 学習目標の予告 | 冒頭「持ち帰ってもらう3つ」 |
| 3 | 前提知識の想起 | HbA1c, 服薬アドヒアランス等 既習概念の利用 |
| 4 | 新情報の提示 | カルテ外の "繋がり情報" 開示 → 3つのフレーム転換 |
| 5 | 学習のガイダンス | 症例への適用表(各転換を症例に当てはめる) |
| 6 | 学習者の応答誘発 | 隣と30秒の対話、明日の1問 |
| 7 | フィードバック | ファシリテーターからの即時フィードバック(声かけセリフ参照) |
| 8 | 達成度の評価 | 任意の宿題「次回1人1分シェア」 |
| 9 | 保持と転移 | チートシート配布 + 半径を広げる視点提示 |

### 学習目標(ブルーム分類法)

- **理解レベル**: WHO/NHS の3つのフレーム転換を自分の言葉で説明できる
- **適用レベル**: 1人の患者で「繋がりを意識した1問」を実施できる
- **分析レベル**: 自分の診療の中に "見落とされた繋がり" を特定できる
- **(発展)創造レベル**: 自院の外来導線・チーム運営のどこにシステム的な詰まりがあるかを言語化できる

> 初期研修医は理解〜適用、専攻医は分析〜創造まで届くことを期待。
> ただし **明示的な層分けはせず**、誰がどこまで届いても良いとする設計。

## 3. ファシリテーター自身への注意

- **「初期研修医はここまで、専攻医はここから」のような露骨な区切りは絶対に言わない**。
  本教材は「視野が広がっていく1本の旅」として設計されている。
- 後半の組織レベルの話に入るとき、「ここからは興味のある人向け」とは言わず、**「次は半径を広げてみましょう」** と言い換える。
- 前半で帰っても何かを得てもらえる作りになっているので、後半に来てもついて来れない参加者がいても、それは設計通り。「全員が同じ深さに到達する必要はない」。
