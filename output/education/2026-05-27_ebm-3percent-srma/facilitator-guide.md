# ファシリテーターガイド — EBM「3%問題」

## 1. インストラクショナルデザイン

### 基本情報
- 対象: 研修医・専攻医（residents版）/ 全スタッフ（allstaff版）
- 時間: 15分（residents） / 15分（allstaff）
- IDモデル: ガニェの9教授事象

### ガニェ9教授事象マッピング表

| 教授事象 | 該当スライド（residents） | 内容 |
|---|---|---|
| 1. 注意の獲得 | なぜ今この話? | 「1日約80本、有益なのは約3%」の数字でインパクト |
| 2. 学習目標の提示 | なぜ今この話?（スライドに目標の文はなし・口頭で） | 「SRMAを批判的に読む目を持つ」 |
| 3. 前提知識の想起 | なぜ今この話? | 既知の「EBMピラミッド」との接続（SRMA爆発の図の前に） |
| 4. 新情報の提示 | Part 2 方法論的欠陥 | AMSTAR-2の重要項目 |
| 5. 学習の手引き | AMSTAR-2 表 / RoB説明 | 具体ツール提示 |
| 6. 練習の機会 | ケースで考える | アスピリン一次予防の問題SRMAを判断 |
| 7. フィードバック | ガイドラインを読む目 | 「ガイドラインの根拠を1本追う」 |
| 8. 評価 | ディスカッション | 最近参照したSRMAを振り返り、根拠を言葉にする |
| 9. 転移の促進 | 明日の外来で使える問い | 翌日からの実践へ直結 |

### ブルーム分類による学習目標

**residents（研修医・専攻医）**
- 理解: SRMAの品質問題（3%問題）の構造を説明できる
- 分析: AMSTAR-2の重要項目を手がかりにSRMAをスクリーニングできる
- 評価: 手元のガイドライン推奨の根拠SRMAの質を評価できる

**allstaff（全スタッフ）**
- 理解: 系統的レビューにも質のばらつきがあることを説明できる
- 適用: 「根拠は?」の問いをチーム内で使える
- 評価: 「論文があるから正しい」思考を自分の場面で問い直せる

## 3. 困ったときの対処法

**「AMSTAR-2なんて普段使わない」と言われたら**
> 「全部やる必要はないです。重要項目をいくつか確認する習慣を、まず主要なガイドライン1つで試してみてください」

**「ガイドラインを否定するの?」と受け取られたら**
> 「否定ではなく、より良い使い方です。根拠を確認することでガイドラインへの信頼が上がります」

**allstaff版でコメディカルスタッフが「関係ない」と感じたら**
> 「皆さんが患者さんに説明する内容のエビデンスの質を知っておくことは、専門職として大切なことです」
