藪医者の学舎 EP.02 — フォントの出典と作り方（2026-10-17）

元の player.html は Google Fonts（fonts.googleapis.com / fonts.gstatic.com）から6書体を読んでいた。
エンジンのフォント埋め込み（animations.jsx の useInlineFontsInto）が全サブセットを取りに行くため、
1回の表示で約1,750件・約45MBの外部通信になっていた。

ここにあるのは、同じ6書体16太さを、このエピソードで使う 442 文字だけに絞った woff2。
Google Fonts の text= パラメータ（文字を指定した絞り込み）で 2026-10-17 に取得した（JetBrains Mono だけは下の理由で取り直した）。
入っている文字の一覧: subset-chars.txt（episode-ep02.js / manabiya-themes.js / animations.jsx / manabiya-video.jsx /
manabiya-video-vertical.jsx / player.html に出てくる文字 + ASCII の印字可能文字）。
台本を書き換えて新しい字が増えたら、その字だけ端末のフォントで表示される（文字化けはしない）。作り直しで直る。

Noto Sans JP と JetBrains Mono は可変フォント（太さを1本で持つ）なので、どの太さも同じファイルを指す（元の配信も同じ）。
fonts.css の unicode-range は、元の Google の配信での各書体の担当範囲と同じ（JetBrains Mono は英数字など99字、
日本語の5書体は ▸ と ✎ 以外）。どの字をどの書体で描くかは、直す前と変わらない。
JetBrains Mono だけは、その99字だけで別に取得した。範囲外の字（▸ など）の形がファイルにあると、Mac は
代わりの書体を探す段階でそのファイル自身を使ってしまうため（元の Google のファイルには ▸ が無く、Menlo で描かれていた）。

作り直しの道具（作者の手元のみ・このリポには含めていない）: rea-lab/cases/20261017_materials-site-network/fix-manabiya-ep02/tools/build_public.mjs
手で作り直すなら: Google Fonts の css2 に text=<subset-chars.txt の字> を付けて取得する（JetBrains Mono は unicode-range の99字だけ）。
fonts.css の unicode-range はそのまま使う。
