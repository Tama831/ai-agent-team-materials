Tama File Sync

Tama File Sync is a small personal tool. It is used only by its owner, to work with the owner's own files in Google Drive.

It is not a public service and is not offered to anyone else.

Privacy Policy

Tama File Sync は、持ち主本人だけが、自分の Google ドライブのファイルを扱うために使う小さな個人用のツールです。公開サービスではありません。
