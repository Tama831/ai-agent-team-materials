巡る天の心臓 — 組み立ての書

哲学はひとつ:「各段で必ず動く」。動かないまま次へ進まない

はじめる前に

印刷: stl_v6/ 全33ファイル (Phrozen Sonic Mini 4K・タフレジン)。プリンタは長期休眠明け → 復活チェックリスト (nFEP膜・LCD露光・Z軸・レジン新調) を先に。
道具: 瞬間接着剤 / 紙 (シム用) / ピンバイス (穴さらい) / ニッパ・ヤスリ / 真鍮φ3棒 60mm・32mm・9.9mm の3本
心構え: 圧入がきつい時は無理せず穴をさらう。渋い噛み合いは「歯当たり調整」(BOM末尾) が織り込み済み

全部品の分解図 — 34個の印刷部品と3本の真鍮軸

Stage 0 「土台を継ぐ」

部品: base_seg0/1/2 (×3)・splice_plate (×3)
  1. 3枚のセグを平面で突き合わせる (切り線 az48/168/288 — 裏スタッドの向きで判別)
  2. 境界の上面 r23.4〜29.4 帯 (浅皿の外・土手の内) に splice_plate を瞬着 ×3ヶ所
  3. 裏返して隠し刻印「ΜΗΧΑΝΗ ΟΥΡΑΝΟΥ」を眺めてニヤリとする (必須工程)
✅ 動作確認: 平らな机でガタつかない・浅皿と土手の円が真円に繋がっている

Stage 1 「地下と背骨」

部品: ub_w1p1 (×2)・ub_pinionA・ub_w3・ub_lantern・spine・planet_gear (×2)・stud_cap (×2)・sun_gear・ring46・真鍮32mm+9.9mm
  1. 裏側: W1P1・W2P2 を吊りスタッドへ (P面が下向き=ベースから遠い側)
  2. 縦シャフト9.9mmの下端に ub_w3 を圧入 → ベース穴 (r24.5) へ下から通す
  3. 表に出た上端へ ub_lantern を圧入・ピン1本が機械中心を向く角度で瞬着 (LNT_PHクロッキング)
  4. spine (背骨) をそっと浅皿へ — 冠環43Tが提灯ピンと噛む
  5. 遊星2個をスタッドに載せ stud_cap を瞬着。中心軸32mmを通し、裏から ub_pinionA・表の z9 に sun_gear を圧入
  6. ring46 を土手に載せる (下面の溝が土手の上に乗る)
✅ 動作確認: 裏ノブを回す → リングが軽く回り、ターンテーブルがごくゆっくり逆方向に回れば地下開通 (リング228回転でターンテーブル1周 — 少し回して冠環の歯が1枚動けば正常)
渋い時: 地下輪列は遊び大きめ設計。逆に飛ぶ/滑る時は吊りスタッド接着前に軸間へ紙シムを入れて詰める

Stage 2 「心臓が動く」

部品: cage_core・bevel_sun・inner_frame・moon_globe・ret_gear・e2p・stud_cap・真鍮60mm
  1. cage_core を背骨のボスへ (雷文の面が上・下面の冠歯24がリング上面のピン24と噛む)
  2. bevel_sun をボス頂部の段に圧入・瞬着 (回らない部品)
  3. inner_frame を第2軸位置へ。真鍮60mmを −x腕 → 月球 → フレームハブ → G (ret_gear) → E1スリーブ → +x腕 の順で通す
  4. 月球 (クレーター上向き基準) と G を瞬着。e2p をスタッドに載せキャップ瞬着
✅ 動作確認: ノブを回す → 12°傾いた心臓が回り、月の額縁が縦に回り、月が公転ごとに1回うなずけば成功。ゆっくり回し続けると傾きの向きも徐々に変わる (歳差)

Stage 3 「大周期を刻む」

部品: saros_idler・saros_seg0/1/2・crown_idler・st1_carrier・ring_seg0/1/2・horizon_seg0/1/2
  1. saros_idler をスタッドへ → saros_seg×3 をダボ接合し滑り壁へ (内歯を提灯ピンに)
  2. crown_idler・st1_carrier を各スタッドへ
  3. ring_seg×3 をダボ接合 → 支柱ピン2本を下面溝に、内縁下面を滑り座 (az20) へ。紙シムで高さ当たり調整
  4. horizon_seg×3 を柱3本の先端ピンに瞬着 — 地平環が全てを囲む
✅ 動作確認: リング6回転でサロスが1周 (時計回り)・12回転で太陽玉が黄道を1周。玉が地平環の腕の下 (すき間2.8mm) をすり抜けるのを見届ける

Stage 4 「電動化」(任意)

部品: motor_mount・coupling・28BYJ-48・ULN2003・ESP32・M3×10 (×2)
  1. hand_knob を抜き coupling に差し替え → motor_mount をベース裏 (y±26) に M3×10 で固定
  2. 28BYJ-48 をマウントへ・D軸を coupling に差し込む
  3. ESP32 + ULN2003 を配線し esp32/meguru_drive/ を書き込み (secrets.h は example から)
✅ 動作確認: lunar モードで1朔望月=リング1回転をリアルタイム刻み (12288 steps・207.6秒/step)。放っておくだけで月も年も食も歳差も、正しい速さで巡り続ける

困った時 (当たり調整早見)

症状処方
ターンテーブルがガタつく浅皿・滑り座に紙シム
天球リングが傾き方向に落ちる滑り座 (az20) の座面に紙シム
提灯まわりが渋い歯先を軽くヤスリで篩う (残差≤7mm³は設計織り込み)
地下輪列が滑る/飛ぶ吊りスタッド接着前に軸間シムで詰め
圧入が入らないピンバイスで穴さらい (光造形の収縮はロット依存)
