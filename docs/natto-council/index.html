北海道産納豆の非加盟国流出に関する
緊急召集の決議 並びに 招集通達

On the Outflow of Hokkaidō-origin Natto to a Non-Member State

標記の件につき、本協議会はこれを看過し得ざる重大事案と認定し、全加盟員を京都国際会議場へ緊急召集の上、対策会議を開催することをここに決議し、通達する。

壱背景認識

近時、本協議会北東アジア監視委員会の継続観測により、北海道産納豆の、非加盟国たる中華人民共和国へ向けた輸出が顕著に増加している事実が把握された。これは協議会創設以来の基本理念「地表における糸の総延長の不拡散」に対する明白かつ現在の脅威である。

当該流出は単なる通商の問題に留まらず、未保護地域への新規ネバネバ曝露を招来し、ひいては世界粘度均衡の崩壊に直結しかねない。よって本件は最高度の警戒をもって処理する。

弐決議事項

本協議会は、第一条（不拡散）及び第七条（緊急対処）に基づき、次のとおり決議する。すなわち、本日付をもって全加盟員を緊急召集し、流出経路の遮断及び封じ込めにつき協議のため、京都国際会議場において臨時総会を開催する。

肆付議議題

  1. 北海道—大連間 流出経路の即時遮断港湾・空路・手土産経路の三層封鎖案について
  2. 「納豆フリー回廊」構想の前倒し非加盟国周縁への緩衝帯設定と粘度モニタリング網の展開
  3. 京都納豆議定書（草案）の採択輸出一俵あたりの糸長上限及び発酵時間の国際標準化
  4. 監視衛星「ネバ・アイ」運用予算の補正軌道上からの糸引き熱源探知能力の増強
  5. その他関西支部より「たれ・からし添付の是非」緊急動議あり（要審議）

伍各員への指示

各員は本通達受領後ただちに参集の準備に入ること。本会議の成否は、地表に残された未曝露地域の運命を左右する。協議会の名誉と、ねばつかぬ明日のために、各位の奮起を切に求める。
